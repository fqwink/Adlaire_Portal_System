# Adlaire ポータルシステム

## 📌 概要
**Adlaire Portal System**は、Node.js（Express）+ SQLiteデータベースで動作する社内ポータルシステムです。
設定データ（タイトル・テーマカラー・お知らせ・カテゴリ・リンク）はすべてSQLiteデータベースに保存され、
複数のブラウザ・端末からアクセスしても同じデータが表示されます。

## ✨ 特徴
- 🗄️ **SQLiteデータベース**: 設定データを一元管理（追加のDBサーバー不要）
- 🌐 **REST API**: `/api/config` で設定の取得・保存・リセットが可能
- 📤 **インポート/エクスポート**: JSON形式でバックアップ可能
- 🎨 カスタマイズ可能: テーマカラー、リンク、カテゴリを自由に編集
- 📱 レスポンシブ対応: PC・スマートフォン両対応
- 🔍 検索機能: リアルタイムでリンクを検索
- 🎯 シンプル設計: 複雑な設定不要

## 📂 ファイル構成
```
adlaire_portal/
├── server.js       # Expressサーバー本体 (静的配信 + REST API)
├── db.js           # SQLiteデータアクセス層 (node:sqlite)
├── seed-data.js     # 初回起動時の初期データ
├── package.json
├── public/
│   ├── portal.html # メイン表示画面
│   └── edit.html   # 設定エディタ
├── data/
│   └── portal.db   # SQLiteデータベースファイル (自動生成、gitignore対象)
└── README.md        # このファイル
```

## 🚀 使い方

### 1. セットアップ
```bash
npm install
npm start
```
サーバーが起動したら、ブラウザで以下のURLを開きます（既定ポートは3000）。
- 閲覧画面: `http://localhost:3000/portal.html`
- 編集画面: `http://localhost:3000/edit.html`

ポートを変更したい場合は `PORT` 環境変数を指定してください。
```bash
PORT=8080 npm start
```

> ℹ️ `node:sqlite` は現時点でNode.jsの実験的機能です。起動時に
> `ExperimentalWarning: SQLite is an experimental feature` という警告が出ますが、動作には問題ありません。
> Node.js **v22.5以上** が必要です。

初回起動時、データベースファイル（`data/portal.db`）が自動的に作成され、初期データ（`seed-data.js`）で初期化されます。

### 2. 設定の編集
1. `edit.html` をブラウザで開きます（データベースから現在の設定を自動的に読み込みます）
2. 左側のエディタでリンクやカテゴリを編集します
3. 右側のプレビューで即座に確認できます
4. 「💾 保存 (データベースに保存)」ボタンをクリック
5. `portal.html` を再読み込みすると変更が即座に反映されます

### 3. バックアップとリストア
- **エクスポート**: 「📤 エクスポート (JSON)」で現在編集中の設定をファイルとしてバックアップ
- **インポート**: 「📥 インポート」で以前エクスポートしたJSONファイルを読み込み（インポート後、「保存」を押すとデータベースに反映されます）
- **デフォルトに戻す**: 「🔄 デフォルトに戻す」でデータベースの内容を初期データ（`seed-data.js`）にリセットします

### 4. チームでの共有
- サーバーを常時起動しておける環境（社内サーバー、VPSなど）にデプロイし、
  チーム全員が同じURLにアクセスすることで、同じデータベースを共有できます

## ⚙️ カスタマイズ

### テーマカラーの変更
編集画面の「テーマカラー」から好きな色を選択できます。
デフォルトは **#00a968**（グリーン）です。

### カテゴリの追加
編集画面下部の「＋ 新しいカテゴリを追加」ボタンから追加できます。

### リンクの追加
各カテゴリ内の「＋ リンクを追加」ボタンから追加できます。

### アイコンの変更
リンクのアイコン部分をクリックすると、30種類の絵文字から選択できます。

### 初期データの変更
初回起動時のデフォルト値を変更したい場合は `seed-data.js` を編集してください
（データベースが既に作成済みの場合、既存の`data/portal.db`には影響しません）。

## 🔒 セキュリティについて
- 本システムは基本的なXSS対策（HTMLエスケープ）とURL検証をクライアント側・サーバー側の両方に実装しています
- サーバー側APIには**認証機能はありません**。`/api/config` への書き込み（PUT/POST）は
  誰でも実行できるため、**信頼できるネットワーク内（社内LANなど）でのみ運用してください**
- インターネットに公開する場合は、リバースプロキシでの認証やVPN経由でのアクセス制限を別途検討してください
- URLは `http://` または `https://`、もしくは相対パス（`/`または`.`で始まる）のみ有効です

## 📝 データ構造（REST API）

### `GET /api/config`
現在の設定をJSONで取得します。

### `PUT /api/config`
設定全体を置き換えます。リクエストボディは以下の形式です。
```json
{
  "title": "Adlaireポータル",
  "themeColor": "#00a968",
  "news": [
    { "date": "2026/02/14", "text": "お知らせ内容" }
  ],
  "categories": [
    {
      "name": "カテゴリ名",
      "links": [
        { "name": "リンク名", "url": "URL", "icon": "🔍" }
      ]
    }
  ]
}
```
バリデーションエラー時は `400` と `{ "error": "..." }` を返します。

### `POST /api/config/reset`
データベースの内容を `seed-data.js` の初期データにリセットします。

## 🗄️ データベーススキーマ
SQLite (`data/portal.db`) に以下の4テーブルで正規化して保存しています。

| テーブル | 内容 |
|---|---|
| `settings` | タイトル・テーマカラー（1行のみ） |
| `news` | お知らせ（日付・本文・並び順） |
| `categories` | カテゴリ名・並び順 |
| `links` | カテゴリに紐づくリンク（名称・URL・アイコン・並び順） |

## 🆘 トラブルシューティング

### Q. `portal.html` を開いてもデータが表示されない
A. サーバー（`npm start`）が起動しているか確認してください。ブラウザから直接HTMLファイルを開く
   （`file://`）のではなく、`http://localhost:3000/portal.html` のようにサーバー経由でアクセスする必要があります。

### Q. 保存したのに変更が反映されない
A. 「保存」ボタンを押した後、`portal.html` を再読み込みしてください。
   それでも反映されない場合は、ブラウザのコンソールやサーバーのログにエラーが出ていないか確認してください。

### Q. 編集画面でプレビューが表示されない
A. サーバーが起動しており、`/api/config` が正しく応答しているか確認してください
   （ブラウザで直接 `http://localhost:3000/api/config` を開いてJSONが返るかチェックできます）。

### Q. インポートしたファイルが読み込めない
A. 正しいJSON形式のファイルか確認してください。
   「📤 エクスポート」ボタンで出力したファイルのみインポート可能です。

### Q. スマホで表示が崩れる
A. ブラウザの表示倍率を100%に設定してください。
   古いブラウザの場合は最新版に更新してください。

### Q. `ExperimentalWarning: SQLite is an experimental feature` という警告が出る
A. Node.js組み込みの `node:sqlite` モジュールが実験的機能であるための警告です。動作には影響ありません。
